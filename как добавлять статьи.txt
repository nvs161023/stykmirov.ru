Что вам нужно будет делать для новой статьи:

Создать файл со статьей (например, blog-new.html).

Открыть articles.json и добавить туда 5 строчек с информацией о новой статье (название, ссылка, картинка).
Всё! Главную страницу (index.html) вы больше никогда не трогаете.

Как это реализовать (готовый код):

Создайте в GitHub файл articles.json и вставьте туда это:

json
[
  {
    "link": "blog-psy2.html",
    "img": "psy2-photo.jpg",
    "category": "Методология",
    "title": "Что такое PSY 2.0 и почему классическая терапия иногда не работает?",
    "desc": "Узнайте, почему работа с телесными ощущениями может быть эффективнее классического психоанализа."
  },
  {
